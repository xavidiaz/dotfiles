# dotfiles

Personal config for an Omarchy (Arch + Hyprland) desktop, managed with [GNU Stow](https://www.gnu.org/software/stow/).
Each top-level directory is a Stow "package" that mirrors its target location under `$HOME`.

## Packages

App configs (`~/.config/<name>`): `hypr`, `alacritty`, `foot`, `ghostty`, `kitty`, `nvim`, `tmux`, `btop`,
`lazygit`, `keepassxc`, `herdr`, `hyprmoncfg`, `mise`, `wally`, `voxtype`, `xournalpp`, `autostart`,
`git` (global git config), `mimeapps`, `starship`, `tuios` (leader Ctrl+Space),
`fcitx5` (input-method toggle moved off Ctrl+Space so it doesn't steal the tuios/tmux prefix).

Home-root files: `bash` (`.bashrc`, `.bash_profile`), `codespaces` (`~/.ssh/config.d/codespaces`:
SSH entries for the CodeSpaces dev containers, generated by `cs` on the host; see below).

Partial package: `omarchy` — only the small user-facing files (`branding`, `defaults`, `hooks`,
`shell.json`, `omasettings.json`, `light-dark.conf`). The `plugins/` cache, `themes/`, `themed/`,
and `extensions/` are left as local, machine-generated state and are NOT tracked here.
Plugins are instead listed in `omarchy-plugins.txt` (`<id> <git-url>`); `install.sh` runs
`omarchy plugin add` for any that are missing, so every machine gets the same plugins that
`shell.json` references.

Not included:
- `gh` (GitHub CLI config) — just run `gh auth login` on the new machine instead.
- Browser profiles (Brave/Chrome/Edge/Chromium) — not dotfiles, don't belong in git.

## `_system-reference/`

Not a Stow package — just a copy of system-level (root-owned) config files for reference, since
Stow only manages `$HOME`. Currently:

- `etc/keyd/default.conf` — keyd config for Touch Bar Fn-key handling (see
  `~/omarchy-macbook-fixes/02-touchbar.md` for context). Apply manually on a new machine:
  ```
  sudo cp _system-reference/etc/keyd/default.conf /etc/keyd/default.conf
  sudo systemctl restart keyd
  ```

## Bootstrap on a new machine

```bash
sudo pacman -S --needed stow git
git clone https://github.com/xavidiaz/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
gh auth login
```

CodeSpaces (`ssh cs-<name>`, `tuios attach --host cs-<name>`): the `codespaces` package has the
space entries but deliberately no address, since this repo is public. Give each machine the
address once, in a private file that is never committed, and include both:

```bash
printf 'Host cs-*\n  HostName <tailnet IP of the CodeSpaces host>\n' > ~/.ssh/config.d/codespaces-host
chmod 600 ~/.ssh/config.d/codespaces-host
# first line of ~/.ssh/config:
#   Include config.d/*
```

`install.sh` just runs `stow` for every package, backing up any real (non-symlink) files already
in the way under `<file>.pre-stow-backup` instead of overwriting them — same as we had to do here
for `mise/config.toml`, which gets regenerated by mise itself if missing.
